# Changelog

## 1.0.1
- Save import: also reads the second, shorter item list that the game sometimes keeps in the player's inventory. Recently picked-up ingredients (for example Human Heart) were missing from the bag.

## 1.0.0
- First public release.
- English and Russian UI with official in-game names; language toggle.
- 177 ingredients: base game, Dawnguard, Hearthfire, Dragonborn, Fishing, Rare Curios, Saints & Seducers.
- "What can I brew" and "Brew what I need" modes; alchemist skill and perks.
- Bag import from Skyrim SE/AE saves (beta), including Alchemy skill and alchemy perks: any load order, Chrome/Edge folder access, Firefox folder pick, file pick, drag and drop.
